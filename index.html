Frequently Asked Questions

Find quick and simple answers to your most common questions.

What is Java? Answer
Java is a high-level, object-oriented programming language used to develop web, desktop, and enterprise applications.
What is JVM? Answer
JVM stands for Java Virtual Machine. It executes Java bytecode and allows Java programs to run on different platforms.
What is JDK? Answer
JDK stands for Java Development Kit. It provides tools required to develop, compile, and run Java applications.
What is Encapsulation? Answer
Encapsulation is the process of wrapping data and methods into a single unit and restricting direct access to the data.
What is Inheritance? Answer
Inheritance allows one class to acquire the properties and methods of another class using the extends keyword.
What is HTML? Answer
HTML stands for HyperText Markup Language. It is used to create and structure content on web pages.
What are HTML tags? Answer
HTML tags are special keywords enclosed in angle brackets that define the structure and elements of a web page.
What is the difference between HTML and HTML5? Answer
HTML5 is the latest version of HTML that provides new features such as semantic elements, audio, video, canvas, and improved form controls.
What are semantic elements in HTML? Answer
Semantic elements clearly describe their meaning and purpose, such as header, nav, section, article, and footer.
What is the difference between div and span? Answer
The div element is a block-level element used to group larger sections, while span is an inline element used to style or group small portions of content.
